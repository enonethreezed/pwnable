# Player Guide

The objective is to reach root on each node in order.

1. Start at `user1@192.168.56.11`.
2. Enumerate the current machine and use the URL in `~/README.txt` as a reference.
3. After reaching root, read `/root/user.txt`.
4. Use the supplied credentials to SSH to the next node.
5. Repeat until node 11.

The intended paths use standard Linux binaries and deliberately unsafe system configuration. No kernel exploits or custom challenge binaries are required.
